## 📌 Descripción del Proyecto
Esta plataforma web es una herramienta interactiva diseñada para la visualización y aprendizaje de conceptos de Cálculo Integral y Métodos Numéricos. Constituye la primera fase de un proyecto semestral colaborativo orientado a estudiantes de desarrollo de software.

En esta **Fase 1**, se implementó la arquitectura modular completa del sistema y se desarrollaron de forma funcional los primeros 6 módulos interactivos.

---
