📈 Módulo 4: Regla de Simpson

Aproximación del área bajo la curva usando parábolas ajustadas

📖 Fundamento Teórico

La Regla de Simpson (o Regla de Simpson 1/3) es un método de integración numérica que aproxima la integral definida de una función. A diferencia de los métodos anteriores que usaban rectángulos o trapecios (líneas rectas), Simpson utiliza parábolas (polinomios de segundo grado) para ajustar la curva en cada par de subintervalos.

⚠️ Condición Importante

Para aplicar la Regla de Simpson, el número de subintervalos $n$ debe ser un número PAR ($n = 2, 4, 6, \dots$). Esto se debe a que cada parábola necesita 3 puntos para ser definida, cubriendo 2 subintervalos a la vez.

Fórmula de la Regla de Simpson

$$S_n = \frac{\Delta x}{3} \left[ f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) + 2f(x_4) + \dots + 4f(x_{n-1}) + f(x_n) \right]$$

Donde:

$$\Delta x = \frac{b - a}{n} \quad \text{y} \quad x_i = a + i\Delta x$$

Nota el patrón de los coeficientes: 1, 4, 2, 4, 2, ..., 4, 1

💡 Dato Curioso: La Regla de Simpson es tan precisa que da el valor exacto de la integral para cualquier polinomio de grado 3 o menor (como $f(x) = x^3 + 2x^2 - x + 5$), ¡incluso con pocos subintervalos!

Ejemplos Resueltos Paso a Paso

Ejemplo 1: Aproximar $\int_0^2 x^2 dx$ usando la Regla de Simpson con $n = 4$

Paso 1: Calcular $\Delta x$

$$\Delta x = \frac{b - a}{n} = \frac{2 - 0}{4} = 0.5$$

Paso 2: Identificar los puntos $x_i$ y evaluar $f(x_i) = x^2$

$x_0 = 0 \implies f(0) = 0$

$x_1 = 0.5 \implies f(0.5) = 0.25$

$x_2 = 1.0 \implies f(1.0) = 1.00$

$x_3 = 1.5 \implies f(1.5) = 2.25$

$x_4 = 2.0 \implies f(2.0) = 4.00$

Paso 3: Aplicar la fórmula de Simpson (Patrón 1, 4, 2, 4, 1)

$$S_4 = \frac{0.5}{3} [f(0) + 4f(0.5) + 2f(1.0) + 4f(1.5) + f(2.0)]$$

$$S_4 = \frac{1}{6} [0 + 4(0.25) + 2(1.00) + 4(2.25) + 4.00]$$

$$S_4 = \frac{1}{6} [0 + 1.0 + 2.0 + 9.0 + 4.0] = \frac{16}{6} = \frac{8}{3} \approx 2.6667$$

Paso 4: Comparar con el valor exacto

$$\int_0^2 x^2 dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3} \approx 2.6667$$

Conclusión: ¡El error es 0! Como mencionamos en la teoría, Simpson da el valor exacto para polinomios de grado $\le 3$.

Ejemplo 2: Use $S_4$ para aproximar $\int_1^3 \frac{1}{x} dx$

Paso 1: Calcular $\Delta x$

$$\Delta x = \frac{3 - 1}{4} = \frac{2}{4} = 0.5$$

Paso 2: Evaluar $f(x) = \frac{1}{x}$ en los puntos

$x_0 = 1.0 \implies f(1.0) = 1.0000$

$x_1 = 1.5 \implies f(1.5) = 0.6667$

$x_2 = 2.0 \implies f(2.0) = 0.5000$

$x_3 = 2.5 \implies f(2.5) = 0.4000$

$x_4 = 3.0 \implies f(3.0) = 0.3333$

Paso 3: Aplicar la fórmula

$$S_4 = \frac{0.5}{3} [1.0000 + 4(0.6667) + 2(0.5000) + 4(0.4000) + 0.3333]$$

$$S_4 = \frac{1}{6} [1.0000 + 2.6668 + 1.0000 + 1.6000 + 0.3333]$$

$$S_4 = \frac{1}{6} [6.6001] \approx 1.1000$$

Paso 4: Valor exacto

$$\int_1^3 \frac{1}{x} dx = [\ln|x|]_1^3 = \ln(3) - \ln(1) \approx 1.0986$$

Error: $|1.1000 - 1.0986| = 0.0014$. ¡Una aproximación increíblemente buena!
