⛰️ Módulo 14: Integrales con ax² + bx + c

Completar la cuadrada es la llave: todo trinomio se reduce a una de tres formas canónicas

📖 Fundamento Teórico

Cuando el integrando contiene un trinomio cuadrático $ax^2+bx+c$ (dentro de una raíz, en un denominador o multiplicando), el truco maestro es completar la cuadrada:

Identidad base (todo depende del signo de $a$)

$$ax^2+bx+c = a\left(x+\frac{b}{2a}\right)^2 + \left(c-\frac{b^2}{4a}\right)$$

Con el cambio $u = x + \dfrac{b}{2a}$ el trinomio queda libre de término lineal y se reduce a una de las tres formas canónicas:

$$a>0:\; A^2u^2+k^2 \qquad a<0,\ \text{disc.}>0:\; k^2-A^2u^2 \qquad a<0,\ \text{disc.}<0:\; A^2u^2-k^2$$

🪜 Estrategia general (numerador lineal sobre cuadrática)

  1. Separar la derivada: escribe $mx+n = \frac{m}{2a}(2ax+b) + \left(n-\frac{mb}{2a}\right)$.
  2. Primera integral: $\displaystyle\int \frac{f'(x)}{f(x)}dx = \ln|f(x)|$ — sale gratis porque $f'(x)=2ax+b$.
  3. Segunda integral: completa la cuadrada y aplica la forma canónica ($\arctan$, $\ln$ o arco-hiperbólica).

Para raíces: sustituye primero $u=x+\frac{b}{2a}$ y luego usa las fórmulas estándar $\sqrt{k^2-u^2}$ (círculo), $\sqrt{u^2+k^2}$ (hipérbola).

💡 Las tres fórmulas canónicas que debes memorizar: $\displaystyle\int \frac{du}{u^2+k^2}=\frac{1}{k}\arctan\frac{u}{k}$,   $\displaystyle\int \frac{du}{\sqrt{k^2-u^2}}=\arcsin\frac{u}{k}$,   $\displaystyle\int \frac{du}{\sqrt{u^2\pm k^2}}=\ln\left|u+\sqrt{u^2\pm k^2}\right|$.
⚠️ Cuidado con el discriminante: si $\Delta = b^2-4ac \ge 0$ y el intervalo cruza una raíz real de $ax^2+bx+c$, el integrando tiene asíntota (o sale del dominio en las raíces) y la integral definida no existe. El visualizador lo detecta por ti.

📝 Ejemplos Resueltos Paso a Paso

Ejemplo 1: $\displaystyle \int \frac{dx}{x^2+4x+13}$  (caso $\Delta < 0$)

Paso 1: Completar la cuadrada

$$x^2+4x+13 = (x+2)^2 + 9 = u^2 + 3^2,\qquad u = x+2$$

Paso 2: Aplicar la forma canónica de arctangente

$$\int \frac{du}{u^2+3^2} = \frac{1}{3}\arctan\!\left(\frac{u}{3}\right) + C = \frac{1}{3}\arctan\!\left(\frac{x+2}{3}\right) + C$$

✔ Verificación

$$\frac{d}{dx}\left[\frac{1}{3}\arctan\frac{x+2}{3}\right] = \frac{1}{3}\cdot\frac{1}{1+\left(\frac{x+2}{3}\right)^2}\cdot\frac{1}{3} = \frac{1}{(x+2)^2+9} = \frac{1}{x^2+4x+13}\quad ✓$$

Ejemplo 2: $\displaystyle \int \frac{3x+5}{x^2+4x+13}\,dx$  (numerador lineal)

Paso 1: Separar la derivada del denominador

$$3x+5 = \tfrac{3}{2}(2x+4) + \left(5-\tfrac{3}{2}\cdot 4\right) = \tfrac{3}{2}(2x+4) - 1$$

Paso 2: Parte logarítmica + parte arctan

$$\int \frac{\tfrac{3}{2}(2x+4)}{x^2+4x+13}dx = \tfrac{3}{2}\ln\left|x^2+4x+13\right|,\qquad \int \frac{-1}{(x+2)^2+9}dx = -\tfrac{1}{3}\arctan\frac{x+2}{3}$$

Resultado

$$\int \frac{3x+5}{x^2+4x+13}\,dx = \frac{3}{2}\ln\left(x^2+4x+13\right) - \frac{1}{3}\arctan\!\left(\frac{x+2}{3}\right) + C$$

Ejemplo 3: $\displaystyle \int \frac{dx}{\sqrt{5-4x-x^2}}$  (caso círculo, $a < 0$)

Paso 1: Factoriza y completa dentro del radical

$$5-4x-x^2 = -(x^2+4x-5) = 9-(x+2)^2 = 3^2-u^2,\qquad u=x+2$$

Paso 2: Forma canónica de arco seno

$$\int \frac{du}{\sqrt{3^2-u^2}} = \arcsin\!\left(\frac{u}{3}\right)+C = \arcsin\!\left(\frac{x+2}{3}\right)+C$$

✔ Dominio

La raíz exige $9-(x+2)^2>0 \iff -5 \le x \le 1$: semicírculo de radio $3$ centrado en $x=-2$. Derivar $\arcsin\frac{x+2}{3}$ devuelve $\frac{1}{\sqrt{9-(x+2)^2}}$ ✓
