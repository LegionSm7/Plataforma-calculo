🌀 Módulo 16: Funciones Hiperbólicas Inversas

Las gemelas logarítmicas del seno y coseno hiperbólico: $\operatorname{arsinh}$, $\operatorname{arcosh}$, $\operatorname{artanh}$

📖 Fundamento Teórico

Las funciones hiperbólicas inversas son en realidad logaritmos disfrazados. Sus derivadas tienen la misma silueta que las trigonométricas inversas, pero con signos dictados por la identidad fundamental $\cosh^2 t - \sinh^2 t = 1$:

Derivadas de las inversas hiperbólicas (¡recuérdalas como logaritmos!)

$$\frac{d}{dx}\operatorname{arsinh}\frac{x}{a} = \frac{1}{\sqrt{x^2+a^2}} \qquad \frac{d}{dx}\operatorname{arcosh}\frac{x}{a} = \frac{1}{\sqrt{x^2-a^2}} \qquad \frac{d}{dx}\operatorname{artanh}\frac{x}{a} = \frac{1}{a}\cdot\frac{1}{1-(x/a)^2} = \frac{a}{a^2-x^2}$$

Formas logarítmicas equivalentes:

$$\operatorname{arsinh}x = \ln\!\left(x+\sqrt{x^2+1}\right), \qquad \operatorname{arcosh}x = \ln\!\left(x+\sqrt{x^2-1}\right), \qquad \operatorname{artanh}x = \tfrac{1}{2}\ln\frac{1+x}{1-x}$$

🪜 Estrategia general

  1. Reconocer la silueta: $\sqrt{x^2+a^2} \to \operatorname{arsinh}$;   $\sqrt{x^2-a^2} \to \operatorname{arcosh}$;   $a^2-x^2 \to \operatorname{artanh}$.
  2. Alinear el argumento: si viene $kx$ en lugar de $x$, factoriza la constante ($\int \frac{dx}{\sqrt{4x^2+9}} = \frac12 \operatorname{arsinh}\frac{2x}{3}$).
  3. Completar la cuadrada primero si el polinomio tiene término lineal: $u = x + \frac{b}{2a}$ reduce todo a las tres siluetas anteriores (puente con el Módulo 15).
  4. Numerador presente: si aparece $f'(x)$ arriba, usa $\int \operatorname{arcosh}(u)\,du = u\,\operatorname{arcosh}u - \sqrt{u^2-1} + C$ análogamente para $\operatorname{arsinh}$.
💡 Dato clave: $\operatorname{arsinh}$ está definida en todo $\mathbb{R}$ (su gráfica es una curva suave tipo "S"), $\operatorname{arcosh}$ solo existe para $|x|\ge 1$ (dominio restringido), y $\operatorname{artanh}$ solo para $|x|<1$ — sus asíntotas verticales en $x=\pm a$ hacen que muchas integrales definidas diverjan. El visualizador te avisa.
⚠️ Signos opuestos entre familias: observa que $\sqrt{x^2 - a^2}$ pide $\operatorname{arcosh}$ (fuera del intervalo $[-a,a]$) mientras que $\sqrt{a^2 - x^2}$ pide $\arcsin$ (dentro). Un signo menos mal colocado cambia por completo la antiderivada.

📝 Ejemplos Resueltos Paso a Paso

Ejemplo 1: $\displaystyle \int \frac{dx}{\sqrt{4x^2+9}}$  (forma $\operatorname{arsinh}$)

Paso 1: Alinear la silueta $\sqrt{u^2+a^2}$

$$4x^2+9 = (2x)^2 + 3^2, \qquad u = 2x,\quad du = 2\,dx$$

Paso 2: Aplicar la fórmula canónica

$$\int \frac{dx}{\sqrt{(2x)^2+3^2}} = \frac{1}{2}\int \frac{du}{\sqrt{u^2+3^2}} = \frac{1}{2}\operatorname{arsinh}\!\left(\frac{u}{3}\right) + C = \frac{1}{2}\operatorname{arsinh}\!\left(\frac{2x}{3}\right) + C$$

✔ Verificación

$$\frac{d}{dx}\left[\frac{1}{2}\operatorname{arsinh}\frac{2x}{3}\right] = \frac{1}{2}\cdot\frac{1}{\sqrt{1+\left(\frac{2x}{3}\right)^2}}\cdot\frac{2}{3} = \frac{1}{\sqrt{9+4x^2}} \quad ✓$$

Ejemplo 2: $\displaystyle \int \frac{dx}{9-x^2}$  (forma $\operatorname{artanh}$, también sale por fracciones parciales)

Paso 1: Silueta $a^2 - x^2$ con $a = 3$

$$\int \frac{dx}{3^2-x^2} = \frac{1}{3}\operatorname{artanh}\!\left(\frac{x}{3}\right) + C, \qquad |x| < 3$$

Paso 2: Equivalencia logarítmica (fracciones parciales)

$$\frac{1}{9-x^2} = \frac{1}{6}\left(\frac{1}{3-x} + \frac{1}{3+x}\right) \;\Rightarrow\; \frac{1}{6}\ln\left|\frac{3+x}{3-x}\right| + C = \frac{1}{3}\operatorname{artanh}\!\left(\frac{x}{3}\right) + C$$

✔ Observación

Para $|x|>3$ la misma primitiva se escribe con $\operatorname{arcoth}$: $\displaystyle \int \frac{dx}{x^2-9} = -\frac{1}{3}\operatorname{arcoth}\!\left(\frac{x}{3}\right)+C$. ¡El dominio decide cuál usar!

Ejemplo 3: $\displaystyle \int \operatorname{arcosh}(2x)\,dx$  (función inversa como integrando)

Paso 1: Fórmula de integración de la inversa

$$\int \operatorname{arcosh}(u)\,du = u\,\operatorname{arcosh}(u) - \sqrt{u^2-1} + C$$

Paso 2: Ajuste de constante con $u = 2x$, $du = 2dx$

$$\int \operatorname{arcosh}(2x)\,dx = \frac{1}{2}\left[u\,\operatorname{arcosh}u - \sqrt{u^2-1}\right]_{u=2x} = x\,\operatorname{arcosh}(2x) - \frac{1}{2}\sqrt{4x^2-1} + C$$

✔ Verificación

$$\frac{d}{dx}\left[x\,\operatorname{arcosh}(2x) - \frac{1}{2}\sqrt{4x^2-1}\right] = \operatorname{arcosh}(2x) + \frac{x}{\sqrt{4x^2-1}} - \frac{x}{\sqrt{4x^2-1}} = \operatorname{arcosh}(2x) \quad ✓$$
