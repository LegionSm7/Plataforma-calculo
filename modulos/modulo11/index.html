🧭 Módulo 11: Integrales Trigonométricas Inversas

Cuando la derivada de una función inversa aparece "al revés" en el integrando

📖 Las Tres Fórmulas Clásicas

Recuerda las derivadas inversas: $\frac{d}{dx}(\arcsin x) = \frac{1}{\sqrt{1-x^2}}$, $\frac{d}{dx}(\arctan x) = \frac{1}{1+x^2}$ y $\frac{d}{dx}(\arcsec x) = \frac{1}{|x|\sqrt{x^2-1}}$. Integrando en ambas direcciones obtenemos las tres plantillas fundamentales:

$$\int \frac{du}{\sqrt{a^2-u^2}} = \arcsin\!\left(\frac{u}{a}\right) + C$$

Aplica cuando el denominador tiene una raíz de diferencia: $a^2 - u^2$.

$$\int \frac{du}{a^2+u^2} = \frac{1}{a}\arctan\!\left(\frac{u}{a}\right) + C$$

Aplica con suma de cuadrados en el denominador (sin raíz).

$$\int \frac{du}{u\sqrt{u^2-a^2}} = \frac{1}{a}\,\arcsec\!\left(\frac{|u|}{a}\right) + C$$

Aplica con raíz de diferencia $u^2 - a^2$ y un factor $u$ extra.

🪜 Método de Reconocimiento

  1. Completa cuadrados si el denominador es un trinomio: $x^2 + 2x + 5 = (x+1)^2 + 4$.
  2. Identifica la plantilla: ¿suma de cuadrados ($\arctan$), raíz con diferencia ($\arcsin$) o raíz con $u$ afuera ($\arcsec$)?
  3. Haz la sustitución $u = g(x)$ y ajusta constantes para que aparezca $du$.
  4. Simplifica el argumento $\frac{u}{a}$ y verifica derivando tu respuesta.
💡 Ojo con el factor 1/a: en $\arctan$ y $\arcsec$ la constante $\frac{1}{a}$ multiplica toda la respuesta. Es el error más común en exámenes.

✏️ Ejemplos Resueltos

Ejemplo 1: Completar cuadrados

$$\int \frac{dx}{x^2 + 4x + 13}$$

Paso 1: Completar cuadrados en el denominador.

$$x^2 + 4x + 13 = (x+2)^2 + 9 = u^2 + 3^2, \quad u = x+2,\; du = dx$$

Paso 2: Aplicar la plantilla de $\arctan$ con $a = 3$.

$$\int \frac{du}{u^2 + 3^2} = \frac{1}{3}\arctan\!\left(\frac{u}{3}\right) + C$$

Resultado:

$$\int \frac{dx}{x^2+4x+13} = \frac{1}{3}\arctan\!\left(\frac{x+2}{3}\right) + C$$

Ejemplo 2: Sustitución con arcseno

$$\int \frac{dx}{\sqrt{4 - 9x^2}}$$

Paso 1: Reescribir como diferencia de cuadrados.

$$\sqrt{4 - 9x^2} = \sqrt{2^2 - (3x)^2} \;\Rightarrow\; u = 3x,\; du = 3\,dx$$

Paso 2: Ajustar la constante y aplicar la plantilla $\arcsin$ con $a=2$.

$$\frac{1}{3}\int \frac{du}{\sqrt{2^2 - u^2}} = \frac{1}{3}\arcsin\!\left(\frac{u}{2}\right) + C$$

Resultado:

$$\int \frac{dx}{\sqrt{4-9x^2}} = \frac{1}{3}\arcsin\!\left(\frac{3x}{2}\right) + C$$
