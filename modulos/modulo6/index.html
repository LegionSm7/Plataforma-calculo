🧮 Módulo 6: Integración Directa

Fórmulas básicas de integración inmediata y antiderivadas

📖 Fundamento Teórico

La Integración Directa (o integración inmediata) consiste en encontrar la antiderivada de una función aplicando directamente las fórmulas básicas de integración, que son el proceso inverso a la derivación. El resultado de una integral indefinida siempre es una familia de funciones, representada por la constante de integración $C$.

Fórmulas Básicas de Integración Directa

1. Potencia: $\displaystyle \int x^n dx = \frac{x^{n+1}}{n+1} + C, \quad (n \neq -1)$

2. Logarítmica: $\displaystyle \int \frac{1}{x} dx = \ln|x| + C$

3. Exponencial: $\displaystyle \int e^x dx = e^x + C \quad \text{y} \quad \int a^x dx = \frac{a^x}{\ln(a)} + C$

4. Trigonométricas:

$\displaystyle \int \sin(x) dx = -\cos(x) + C$

$\displaystyle \int \cos(x) dx = \sin(x) + C$

$\displaystyle \int \sec^2(x) dx = \tan(x) + C$

💡 Propiedad de Linealidad: La integral de una suma/resta es la suma/resta de las integrales, y las constantes multiplicativas pueden salir de la integral: $$\int [a \cdot f(x) \pm b \cdot g(x)] dx = a \int f(x) dx \pm b \int g(x) dx$$

📝 Ejemplos Resueltos Paso a Paso

Ejemplo 1: Integrar un polinomio $\int (3x^2 - 4x + 5) dx$

Paso 1: Aplicar la propiedad de linealidad

Separamos la integral en tres partes y sacamos las constantes:

$$\int (3x^2 - 4x + 5) dx = 3\int x^2 dx - 4\int x dx + 5\int 1 dx$$

Paso 2: Aplicar la fórmula de la potencia $\int x^n dx = \frac{x^{n+1}}{n+1}$

$$3\left(\frac{x^3}{3}\right) - 4\left(\frac{x^2}{2}\right) + 5(x) + C$$

Paso 3: Simplificar la expresión

$$x^3 - 2x^2 + 5x + C$$

Verificación: Si derivamos $F(x) = x^3 - 2x^2 + 5x$, obtenemos $F'(x) = 3x^2 - 4x + 5 = f(x)$. ¡Correcto!

Ejemplo 2: Integrar funciones exponenciales y trigonométricas $\int (2e^x + \cos x) dx$

Paso 1: Separar la integral

$$\int 2e^x dx + \int \cos x dx = 2\int e^x dx + \int \cos x dx$$

Paso 2: Aplicar fórmulas directas

Recordamos que $\int e^x dx = e^x + C$ y $\int \cos x dx = \sin x + C$.

$$2(e^x) + \sin(x) + C$$

Paso 3: Resultado final

$$2e^x + \sin(x) + C$$

Conclusión: La antiderivada de una suma de funciones es la suma de sus antiderivadas individuales.

Ejemplo 3: Integrar radicales y fracciones $\int \left(\frac{1}{x} + \sqrt{x}\right) dx$

Paso 1: Reescribir la función con exponentes

Recordamos que $\sqrt{x} = x^{1/2}$. La integral queda:

$$\int (x^{-1} + x^{1/2}) dx = \int \frac{1}{x} dx + \int x^{1/2} dx$$

Paso 2: Aplicar fórmulas (Logarítmica y Potencia)

Para $1/x$ usamos la logarítmica, y para $x^{1/2}$ usamos la potencia con $n=1/2$:

$$\ln|x| + \frac{x^{(1/2) + 1}}{(1/2) + 1} + C$$

Paso 3: Simplificar el exponente y la fracción

$$\ln|x| + \frac{x^{3/2}}{3/2} + C = \ln|x| + \frac{2}{3}x^{3/2} + C$$

También se puede escribir como: $\ln|x| + \frac{2}{3}x\sqrt{x} + C$
