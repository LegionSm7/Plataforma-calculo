🌊 Módulo 10: Integrales Trigonométricas

Potencias de sen/cos, identidades de reducción y funciones trigonométricas

📖 Fundamento Teórico

Las integrales trigonométricas se resuelven combinando las fórmulas básicas con identidades pitagóricas y de ángulo doble que transforman potencias en sumas integrables.

Identidades Clave

$$\sin^2 x = \frac{1-\cos 2x}{2} \qquad \cos^2 x = \frac{1+\cos 2x}{2}$$

$$\sin x\cos x = \frac{\sin 2x}{2} \qquad \sin^2 x + \cos^2 x = 1$$

$$\int \sin u\,du = -\cos u + C \qquad \int \cos u\,du = \sin u + C$$

🪜 Estrategia según el tipo

  1. Potencias impares de sen o cos: separa un factor, convierte el resto con $\sin^2+\cos^2=1$ y sustituye ($u=\cos x$ o $u=\sin x$).
  2. Potencias pares de ambas: aplica dos veces las identidades de ángulo doble para bajar potencias.
  3. Productos sen·cos: usa la identidad del ángulo doble directamente.
  4. sec², csc²: son derivadas directas: $\int \sec^2 u\,du = \tan u + C$.
  5. sec·tan y csc·cot: $\int \sec u\tan u\,du = \sec u + C$, $\int \csc u\cot u\,du = -\csc u + C$.
💡 Truco memorable: "si sobra un sen o cos, guarda uno para el du y siembra el resto"; "si todos son pares, baja potencias con ángulo doble".
⚠️ Potencias mixtas altas: para $\int \sin^m x \cos^n x\,dx$ con $m,n$ grandes conviene reducir recursivamente; aquí nos enfocamos en los casos clásicos de examen (m,n ≤ 4).

📝 Ejemplos Resueltos Paso a Paso

Ejemplo 1: Potencia impar $\displaystyle \int \sin^3 x \, dx$

Paso 1: Separar un factor sen x

$$\int \sin^3 x\,dx = \int \sin^2 x \cdot \sin x\,dx = \int (1-\cos^2 x)\,\sin x\,dx$$

Paso 2: Sustituir $u = \cos x$

$$du = -\sin x\,dx \quad\Rightarrow\quad -\int (1-u^2)\,du = -u + \frac{u^3}{3} + C$$

Paso 3: Regresar a $x$

$$\int \sin^3 x\,dx = -\cos x + \frac{\cos^3 x}{3} + C$$

Ejemplo 2: Potencia par $\displaystyle \int \sin^2 x \, dx$

Paso 1: Identidad de ángulo doble

$$\int \frac{1-\cos 2x}{2}\,dx = \frac{1}{2}\int 1\,dx - \frac{1}{2}\int \cos 2x\,dx$$

Paso 2: Integrar término a término

$$= \frac{x}{2} - \frac{\sin 2x}{4} + C$$

✔ Caso notable

$$\int_0^{2\pi} \sin^2 x\,dx = \pi \qquad \text{(el promedio de } \sin^2 \text{ es } 1/2)$$
