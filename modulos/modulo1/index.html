📊 Módulo 1: Sumas de Riemann

Aproximación del área bajo la curva mediante sumas

📖 Fundamento Teórico

Las Sumas de Riemann son un método para aproximar el área bajo una curva dividiendo el intervalo $[a, b]$ en $n$ subintervalos de igual ancho $\Delta x$.

Fórmula del ancho de subintervalo:

$$\Delta x = \frac{b - a}{n}$$

📍 Suma Izquierda ($L_n$)

$$L_n = \sum_{i=0}^{n-1} f(x_i) \Delta x$$

Usa el extremo izquierdo de cada subintervalo.

📍 Suma Derecha ($R_n$)

$$R_n = \sum_{i=1}^{n} f(x_i) \Delta x$$

Usa el extremo derecho de cada subintervalo.

📍 Punto Medio ($M_n$)

$$M_n = \sum_{i=1}^{n} f(\bar{x}_i) \Delta x, \quad \bar{x}_i = \frac{x_{i-1} + x_i}{2}$$

Usa el punto medio de cada subintervalo.

💡 Nota: A medida que $n \to \infty$, las tres sumas convergen al valor exacto de la integral definida $\int_a^b f(x) dx$.

📝 Ejemplos Resueltos Paso a Paso

Ejemplo 1: $f(x) = x^2$ en $[0, 2]$ con $n = 4$

Paso 1: Calcular $\Delta x$

$$\Delta x = \frac{b - a}{n} = \frac{2 - 0}{4} = 0.5$$

Paso 2: Identificar los puntos

$x_0 = 0, \quad x_1 = 0.5, \quad x_2 = 1, \quad x_3 = 1.5, \quad x_4 = 2$

Paso 3: Suma Izquierda ($L_4$)

$$L_4 = \Delta x [f(0) + f(0.5) + f(1) + f(1.5)]$$

$$L_4 = 0.5 [0 + 0.25 + 1 + 2.25] = 0.5 \times 3.5 = 1.75$$

Paso 4: Suma Derecha ($R_4$)

$$R_4 = \Delta x [f(0.5) + f(1) + f(1.5) + f(2)]$$

$$R_4 = 0.5 [0.25 + 1 + 2.25 + 4] = 0.5 \times 7.5 = 3.75$$

Paso 5: Punto Medio ($M_4$)

Puntos medios: $\bar{x}_1 = 0.25, \bar{x}_2 = 0.75, \bar{x}_3 = 1.25, \bar{x}_4 = 1.75$

$$M_4 = 0.5 [f(0.25) + f(0.75) + f(1.25) + f(1.75)]$$

$$M_4 = 0.5 [0.0625 + 0.5625 + 1.5625 + 3.0625] = 0.5 \times 5.25 = 2.625$$

Paso 6: Valor exacto (para comparar)

$$\int_0^2 x^2 dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3} \approx 2.6667$$

Conclusión: $M_4$ es la aproximación más cercana al valor exacto.

Ejemplo 2: $f(x) = \sqrt{x}$ en $[0, 4]$ con $n = 4$

Paso 1: Calcular $\Delta x$

$$\Delta x = \frac{4 - 0}{4} = 1$$

Paso 2: Puntos del intervalo

$x_0 = 0, \quad x_1 = 1, \quad x_2 = 2, \quad x_3 = 3, \quad x_4 = 4$

Paso 3: Suma Izquierda ($L_4$)

$$L_4 = 1 \cdot [\sqrt{0} + \sqrt{1} + \sqrt{2} + \sqrt{3}]$$

$$L_4 = 0 + 1 + 1.4142 + 1.7321 = 4.1463$$

Paso 4: Suma Derecha ($R_4$)

$$R_4 = 1 \cdot [\sqrt{1} + \sqrt{2} + \sqrt{3} + \sqrt{4}]$$

$$R_4 = 1 + 1.4142 + 1.7321 + 2 = 6.1463$$

Paso 5: Punto Medio ($M_4$)

Puntos medios: $0.5, 1.5, 2.5, 3.5$

$$M_4 = 1 \cdot [\sqrt{0.5} + \sqrt{1.5} + \sqrt{2.5} + \sqrt{3.5}]$$

$$M_4 = 0.7071 + 1.2247 + 1.5811 + 1.8708 = 5.3837$$

Paso 6: Valor exacto

$$\int_0^4 \sqrt{x} dx = \left[\frac{2x^{3/2}}{3}\right]_0^4 = \frac{2 \cdot 8}{3} = \frac{16}{3} \approx 5.3333$$

Conclusión: Nuevamente, $M_4$ ofrece la mejor aproximación.
