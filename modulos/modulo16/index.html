🧩 Módulo 16: Integración por Fracciones Parciales

Descomponer funciones racionales complejas en piezas simples integrables

📖 Fundamento Teórico

Toda función racional $\frac{P(x)}{Q(x)}$ (con grado de $P$ menor que el de $Q$) puede descomponerse en una suma de fracciones elementales que se integran con logaritmos y arctangentes.

Los Cuatro Casos de Descomposición

$$\text{Factor lineal simple: } \frac{A}{ax+b} \;\Rightarrow\; \int = \frac{A}{a}\ln|ax+b|$$

$$\text{Factor lineal repetido: } \frac{A_1}{(ax+b)} + \frac{A_2}{(ax+b)^2} + \cdots$$

$$\text{Factor cuadrático irred. simple: } \frac{Ax+B}{ax^2+bx+c} \;\Rightarrow\; \ln + \arctan$$

$$\text{Factor cuadrático repetido: } \frac{A_1x+B_1}{ax^2+bx+c} + \frac{A_2x+B_2}{(ax^2+bx+c)^2} + \cdots$$

🪜 Protocolo

  1. Verificar propia: si grado($P$) ≥ grado($Q$), divide primero polinomialmente.
  2. Factorizar $Q(x)$ en factores lineales y cuadráticos irreducibles.
  3. Escribir la plantilla con coeficientes desconocidos según los casos.
  4. Determinar coeficientes: multiplica por $Q$, iguala potencias o sustituye raíces convenientes.
  5. Integrar pieza por pieza ($\int \frac{dx}{ax+b}$ da logaritmo; completar cuadrado + arctan para lo demás).
💡 Atajo de la raíz: multiplica por el denominador común y evalúa en cada raíz: si $Q=(x-1)(x+2)$, entonces $A=\left.\frac{P}{x+2}\right|_{x=1}$. Rápido para factores lineales distintos.
⚠️ Trampa común: olvidar que un numerador sobre cuadrático irreducible es $Ax+B$ (¡dos incógnitas!), no solo $A$.

📝 Ejemplos Resueltos Paso a Paso

Ejemplo 1: Factores lineales distintos $\displaystyle \int \frac{dx}{x^2-x-6}$

Paso 1: Factorizar y plantear

$$x^2-x-6 = (x-3)(x+2) \qquad \frac{1}{(x-3)(x+2)} = \frac{A}{x-3} + \frac{B}{x+2}$$

Paso 2: Determinar coeficientes (evaluar en raíces)

$$1 = A(x+2)+B(x-3) \;\Rightarrow\; x=3: A=\tfrac{1}{5}; \qquad x=-2: B=-\tfrac{1}{5}$$

Paso 3: Integrar cada parcial

$$\int \frac{dx}{x^2-x-6} = \frac{1}{5}\ln|x-3| - \frac{1}{5}\ln|x+2| + C = \frac{1}{5}\ln\left|\frac{x-3}{x+2}\right| + C$$

Ejemplo 2: Con cuadrático irreducible $\displaystyle \int \frac{dx}{x(x^2+4)}$

Paso 1: Plantilla correcta

$$\frac{1}{x(x^2+4)} = \frac{A}{x} + \frac{Bx+C}{x^2+4}$$

Paso 2: Resolver el sistema

$$1 = A(x^2+4) + (Bx+C)x \;\Rightarrow\; A=\tfrac14,\; B=-\tfrac14,\; C=0$$

Paso 3: Integrar (logaritmo + logaritmo)

$$\int \frac{dx}{x(x^2+4)} = \frac{1}{4}\ln|x| - \frac{1}{8}\ln(x^2+4) + C$$
